# 当前开发方向

网页现在统一使用原版 FreeCAD MCP 的通用执行能力。旧 CAD MCP、固定修改菜单和内部编辑 API 已删除，不作为回退路径。图纸读取、预览和转换仍由后端文件服务提供。

本轮先完成自然语言到自主编程、执行反馈、纠错和成果交付的完整流程。任务副本、取消、成果下载、打开成果继续同一会话由后端管理，不为红线、图框等具体问题新增业务工具。

FreeCAD 往返的单位、坐标、块、文字、中文及专业对象兼容性按用户要求暂缓修复。下一步根据用户临时提出的工程任务评估上界，分别记录理解、执行、文件兼容和成果发布问题。

详见 [自主执行接入](autonomous-agent.md) 和 [历史兼容性记录](freecad-validation.md)。
