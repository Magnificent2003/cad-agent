# 网页自主执行接入

日期：2026-09-22。

## 当前交付

网页统一连接 4096 智能体，唯一 MCP 为原版 FreeCAD MCP；通过 `execute_code` 自主检查 API、编写代码、观察错误、修正并重新验证文件。没有为红线提取、图框裁剪或某个具体问题新增专用编辑工具。

删除了旧 `cad_mcp/` 源码、`/internal` CAD 接口、固定编辑操作实现、几何检查工具链，以及独立的 4097 实验智能体入口。旧会话保留查看并标记为历史，新建会话进入唯一 FreeCAD 流程。若运行时接入了旧 CAD MCP 或 FreeCAD 未连接，后端拒绝任务，不回退。项目还隔离了引擎的用户目录配置发现和外部权限覆盖。

后端的 ezdxf/ODA 仅承担文件导入、读取、预览、下载转换和历史版本恢复。它们不再向智能体提供另一套编辑动作。

## 文件与任务

`backend/app/agent_tasks.py` 为每轮准备当前版本副本，并提供 `input/`、`scratch/`、`output/`。模型可以在 FreeCAD 中自由组合操作，输出任意格式的文件；DXF/DWG 会另行导入以生成网页预览。输入副本哈希发生变化、输出目录被替换或复制期间文件变化时，本轮不发布。隐藏、临时和不完整文件不作为成果；符号链接不作为交付文件。

输出快照在 `data/artifacts/`，数据库记录任务、会话、来源图纸、版本、文件哈希和后续图纸。网页可下载成果，点击“打开并继续”后，同一会话绑定成果图纸，下一轮重新生成该图纸的文件上下文。

原版 FreeCAD Python 执行不提供操作系统沙箱，提示词中的目录范围属于操作约定。平台收集文件时另做路径检查；本项目仍是本机工作台。

FreeCAD 是共享图形进程，同一时刻只接受一个文件任务。取消后请求停止模型，等待已经开始的 FreeCAD 操作结束，不发布本轮候选成果。服务重启将未完成任务标记为中断，不自动重放代码。单轮最多等待一小时；卡住的 FreeCAD 可通过统一启动终端的 Ctrl+C 一起停止后重启。

## 本机验证

- 后端测试：41 项通过，覆盖副本交接、原图保留、任意格式和嵌套成果、同会话切换成果、旧链路拒绝、取消和共享 FreeCAD 串行使用等。
- 浏览器测试：7 项通过，覆盖下载、打开成果继续对话、旧会话只读，以及原有 SVG 看图和上传流程。
- Ruff、前端 TypeScript 检查和生产构建通过。
- 真实模型通过网页 API 完成两轮任务，共调用 37 次 FreeCAD 工具；未调用旧工具。第一轮 31 次调用，模型遇到两次 Python 错误并自行修正。

第一轮使用新建的三实体 DXF，仅给自然语言要求：改变圆半径、加入文字、保留其余对象，并输出图纸和清单。模型交付 `reviewed.dxf`、`reviewed.FCStd`、`report.csv`。独立 ezdxf 回读确认：一个圆，圆心 (20,20,0) 不变，半径 7 → 10.5，文字包含 SOURCE 和 REVIEWED，输入下载内容哈希不变。

随后通过成果打开接口切换到 reviewed.dxf，在同一会话提出不同的只读统计要求，成功生成 `followup.json`，其中记录半径 10.5 及两处文字。真实浏览器确认四个文件卡片、原会话和继续输入均可用。

验证证据保存在本机 `.runtime/web-agent-validation/`：

- `request.json`、`messages.json`、`final-messages.json`：任务与可见会话。
- `independent-check.json`：独立回读结果。
- `artifacts.json`、`opened.json`、`followup-artifacts.json`：成果发布和继续对话。
- `reviewed.dxf`、`reviewed.FCStd`、`report.csv`、`followup.json`：真实交付。
- `workbench.png`：真实网页截图。

完整代码及工具反馈仍在 `.runtime/agent/data/opencode/` 的会话记录中。测试脚本只负责提交自然语言、下载和独立验收；修改代码由模型自行生成。

## 本轮明确暂缓的范围

没有修复 FreeCAD 对真实施工图的单位、坐标、块、文字、中文或专业对象保真问题，也没有声称复杂工程图已通过无损编辑验收。本轮验收对象是自主执行与网页成果流程；文件兼容性历史证据见 [早期实测](freecad-validation.md)。

## 用户测试入口

```bash
bash scripts/dev.sh
```

打开 http://127.0.0.1:5173，选择自己的工程图并新建对话。可自行更换任务要求，观察模型的实际工具调用、生成文件和未完成事项。无需另开实验端口，也无需手动指定输入副本。
