# 前端验收记录

验证日期：2026-09-21。界面在本机 Chromium 中通过 Vite 访问真实 FastAPI 服务；真实会话由 OpenCode 与已配置的模型处理。

## 构建与接口夹具测试

实际版本：React 19.3.0、TypeScript 5.9.3、Vite 7.3.6、Playwright 1.63.0。版本锁定在 `frontend/package-lock.json`。

| 检查 | 结果 |
| --- | --- |
| `npm run build` | 通过，TypeScript 类型检查及生产构建成功 |
| `npm run format:check` | 通过 |
| `npm run test:e2e` | 4 / 4 通过 |

四项浏览器回归测试使用独立接口夹具，不调用真实模型；覆盖：

1. 查看历史版本时禁用发送，下载所选历史版本，回到当前版本后恢复输入。
2. SVG 失败后使用 PNG，切换布局请求对应预览，缩放与适应窗口。
3. 发送前订阅会话，提交准确的 `expected_revision`，显示用户消息并停止任务。夹具中的 SSE 连接模拟保持打开，原生流式订阅另由下方真实链路验证。
4. 上传经过 `running`、`metadata: null`、`succeeded` 的中间状态，自动显示图纸；390 px 移动端无横向溢出。

运行方法见 [前端说明](../frontend/README.md)。应用运行时不包含模拟业务数据。

## 真实业务链路

| 场景 | 实际结果 |
| --- | --- |
| 打开现有合成图 | 加载当前 r0002 及真实会话历史，无浏览器脚本错误 |
| 历史与布局 | 切换 r0001 后禁用输入，回到 r0002 后恢复；Model 与 Layout1 均通过各自预览接口加载 |
| 新建真实会话 | 从浏览器发出合成图概况查询，真实 OpenCode/SSE 返回当前版本 r0002 和毫米单位 |
| 停止真实任务 | 提交只读合成图查询后点击停止，服务确认停止后显示“任务已停止”并恢复输入 |
| 上传用户提供 DWG | 通过浏览器文件选择上传 `入口标识.dwg`，完成转换、任务轮询与自动切图，显示完成提示；无需刷新或重新选择图纸 |
| 图纸结果 | 最终导入 ID `e63efa01969942e9918e77a14c64bd21`，r0001；88 图层、4,126 图元；原图单位未指定，界面显示“待确认” |
| 真实图桌面与移动端 | 1440 × 960 桌面及 390 px 移动端成功加载图像；浏览器脚本错误为 0，移动端无横向溢出 |

用户提供的 DWG 在本项浏览器测试中仅进入本地导入、转换与预览流程。模型会话验证使用自动生成的合成图纸。

真实导入验收发现并修复了中间状态问题：后端在导入完成前返回空元数据；前端已统一处理 `null` 与未定义的元数据，避免上传过程中页面崩溃。回归测试加入了此实际中间状态，修复后重新完整验证了 DWG 自动切图和完成提示。
