# 部分 A 阶段报告 0929：v0009 空间事实构建与核实

日期：2026-09-29。阶段：A.1 离线算法原型。**已在真实 v0009 上运行；待工程人工审查，尚未接入 Agent / MCP 或自动布置。**

## 1．本次做成了什么

从原生 DXF 的块实例中恢复建筑参考轮廓，将它们与图面编号、名称及面积表关联，生成带来源的事实清单和空间核对图。预览中的 WIPEOUT 不再使算法漏掉这些原生轮廓。

在本开发案例中，7—10 号厂房的几何、编号、名称与面积形成一致证据；11 号楼仍有面积和场界关系冲突。结果不再是“看到几条线”，而是“哪些线对应哪栋建筑、依据是什么、还有什么没核实”。**这不等于已确定合法场界、施工阶段或可布置空地。**

本轮只新增离线模块、代表测试及本目录成果，没有接入或改变现有 Agent、MCP、布局工具、前端和服务启动流程。README 暂不发布为已完成的场布能力。仓库原有修改与用户归档保留；没有启动服务、调用大模型或另存修改后的 CAD。

## 4．算法如何得到事实

| 环节 | 本次实现 | 不作的推断 |
| --- | --- | --- |
| 原生几何恢复 | 逐实例遍历 INSERT，组合嵌套变换、缩放、旋转、镜像、块基点和阵列位置；保留原始句柄、实例路径、变换与 Z | 不靠块名猜轮廓，不用最大外包框/凸包代替建筑 |
| 参考面提取 | 从有效平面闭合直边对象提取参考多边形；保留带宽和来源 | 不把显示线宽清零，不将参考边界直接视为已确认外墙或占用面 |
| 语义候选 | 在 WCS XY 投影中关联编号与建筑名称，区分表内文字和图面文字；另保留建筑轮廓图层的弱候选 | 不将所有闭合线计为建筑；不将文字高程视为楼层 |
| 表格核对 | 按同块、显式占地面积列头、列范围和行对齐关联表值；要求名称相容 | 不把附近任意数字当面积，不把图签比例当模型尺度 |
| 候选消歧 | 至少三栋、两种面积的共同尺度证据，选择与编号、名称、表值一致的参考轮廓 | 不写死本项目句柄、7—10 编号、坐标、面积或 44.27° |
| 关系核对 | 量测遮罩 XY 覆盖、建筑相对候选场界的面内/面外面积；拆分候选场界的 16 个直线边段 | 不由遮罩推定对象失效，不由候选界外关系判定工程违规 |
| 明示未知 | 分别列出单位、名称/面积、工程阶段、场界角色、不支持几何和未定位建筑 | 不把未知或未显示区域算作空地 |

`status=supported` 仅表示**编号、名称、几何及表面积在图内形成支持证据**。`role_status` 仍为待工程确认，`phase=unknown`，`engineering_confirmed_buildings=0`。XCLIP 未解决和未核实外参下的对象可以保留供审查，但不能作为可靠支持证据。

名称首版采用去空白/标点后的严格一致规则；简称和别名不自动合并。尺度与轮廓消歧的相对聚类阈值为 `1e-4`，面积核对阈值也是 `1e-4`，只服务于这一轮事实筛选，**不是工程验收容差**。原图面积表是独立字段证据，但不是外部权威测量，因此尺度仍需人工确认。

### 5.2 必须保留给人工审查的发现

1. **单位冲突。** 四栋厂房的面积共同支持约 `1 m / 原生单位`；文件头 `$INSUNITS=4` 声明毫米，即 `0.001 m / 原生单位`。输出候选和冲突，不改单位、不用图签 1:600 推导 0.6。
2. **场界不是已核实红线。** `BAE9` 位于“建筑红线”图层，几何面积约 109,823.0762 原生²；表中“建设用地面积”为 43,214 ㎡（`16/71、16/77、16/7A`）。在上述候选尺度下二者不同，可能涉及不同范围或图纸语义，不能假定它们指同一用地。
3. **11 号与候选场界存在具体关系冲突。** 约 503.6866 原生²，即 42.96% 的轮廓在 BAE9 外。四栋厂房均在该候选边界内。本轮显示完整建筑，不裁剪、不把这项关系直接称为违规。
4. **3/4 号未可靠定位。** 表中有配电房，但没有足够编号和名称证据唯一关联轮廓。即使某个小轮廓恰好与 3 号面积相同，也不靠面积单独认领。
5. **遮罩覆盖不是空地，也不是阶段证据。** `6B00` 的 XY 范围覆盖上述主体建筑。本轮量测的是几何覆盖，不模拟最终绘制顺序；不据此认定它们应保留或已废弃。
6. **施工阶段未知。** 图纸说明 `16/1F8` 提到原有建筑物、构筑物未注明保留的应在施工前拆除。这不是“当前已拆除”的证明，也不能用来自动释放建筑占用。

### 5.3 方位角与边段

四栋厂房的**长边**方向约为 **134.266211°**，正交短边约为 **44.266211°**；不能把此前笼统称呼的“44.27°主轴”一律当成长边方向。候选场界的最小外接矩形正交轴为约 44.256053° / 134.256053°，轴族差约 0.010159°。

这说明本例可以从原生建筑与场界几何得到相互接近的方向证据。JSON 同时列出场界全部 16 个原始边段的端点、长度与方向，图中只标较长的代表边段以避免拥挤。**尚未选择某个设施应平行的具体边段，没有将全场 PCA 或包络角直接传给布局工具。**

### 5.4 覆盖范围与未知量

共遍历 12,536 个实例级对象，恢复 2,268 个参考多边形和 980 个文字锚点。产生 5 个主要编号建筑候选，其中 4 个有面积表支持；另有 52 个弱候选或替代轮廓，**不是又识别出 52 栋建筑**。

记录 2,651 个未解析为参考面的对象实例：2,582 个来自曲线、填充、专业代理等不支持类型，69 个来自闭合边界解析问题。问题按类型/图层/原因归并，与语义冲突等合计形成 57 条待核实记录；其来源 ID 仍保留。开放线统计但未自动拼成面。3 个 WIPEOUT 中仅 2 个形成有效简单面，另一个 `20E` 自相交，明确列入问题清单而非自动修复。

这不是完整场景识别率统计，无法由此声称建筑召回率或规范符合率达到某个百分比。图纸中的曲线、庭院孔洞、多个相连建筑、阶段语义、既有设施角色及未知对象定位仍需扩展。当前只证明已独立核对的四栋关键厂房没有继续因显示遮挡或嵌套块而漏掉。
